How this actually protects your text

Every term below maps to a real step this page performs in your browser, using the CryptoJS library. Open the JavaScript console or read script.js to see it happen.

AES encryption

The Advanced Encryption Standard is a symmetric cipher: the same key locks and unlocks the data. This app uses AES-256 in CBC mode, one of the most widely trusted encryption standards in the world, used everywhere from banking to government communications.

Salt

A salt is random data mixed into your password before it becomes a key. It stops attackers from using precomputed password tables (rainbow tables) and guarantees that two people using the identical password still end up with completely different encryption keys.

IV (Initialization Vector)

The IV is a random block fed into the cipher alongside the key. It randomizes the very first block of encryption so that repeating patterns in your plaintext don't produce repeating patterns in your ciphertext.

PBKDF2

Password-Based Key Derivation Function 2 turns your password into a proper cryptographic key by hashing it thousands of times with the salt. The extra work is intentional: it makes brute-force password guessing dramatically slower for an attacker.

Why identical input never looks the same twice

Each time you press Encrypt, this page generates a brand-new random salt and a brand-new random IV, then derives a fresh key from them. Same message, same password, different randomness in, different ciphertext out — every single time. The salt and IV aren't secret, so they travel bundled with the ciphertext, letting Decrypt rebuild the exact same key later without ever storing your password anywhere.
